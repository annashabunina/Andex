# Реализация проекта

## Продуктовые дашборды образовательной платформы «Андекс Университет»

### **1. Данные и модель**

В отчёте используются следующие таблицы:

- `users`, `userentry` — пользователи и события активности;
- `test`, `testquestion`, `testresult` — тесты, вопросы и ответы;
- `problem`, `codesubmit`, `coderun` — практические задачи, отправки решений и запуски кода;
- `calendar_progress`, `calendar_test`, `calendar_problems` — календарные измерения.

Модель объединяет три направления анализа: активность пользователей, результаты тестирования и выполнение практических задач.

### **2. Расчёт показателей DAX**

#### **2.1. Активность пользователей**

Среднее дневное количество уникальных пользователей:

```
_DAU =
AVERAGEX(
    SUMMARIZE(
        'userentry',
        'calendar_progress'[Дата],
        "users",
        DISTINCTCOUNT('userentry'[user_id])
    ),
    [users]
)
```

Среднее месячное количество уникальных пользователей:

```
_MAU =
AVERAGEX(
    SUMMARIZE(
        'userentry',
        calendar_progress[Год],
        'calendar_progress'[Месяц],
        "users",
        DISTINCTCOUNT('userentry'[user_id])
    ),
    [users]
)
```

Показатель Stickiness:

```
_Stickiness = DIVIDE([_DAU], [_MAU])
```

Количество активных пользователей:

```
_is_active_user = SUM(users[is_active_chart])
```

#### **2.2. Удержание пользователей**

Таблица Retention:

```
Retention =
SUMMARIZE(
    userentry,
    userentry[user_id],
    "max_date",
    MAX('userentry'[date_entry_at])
)
```

Разница между датой регистрации и последней активностью:

```
dif =
DATEDIFF(
    Retention[date_joined_at],
    Retention[max_date],
    DAY
)
```

На основе `dif` формируются признаки `retention_3_day`, `retention_7_day`, `retention_14_day` и `retention_30_day`.

#### **2.3. Результаты тестирования**

Общее количество ответов:

```
_all_answers_test =
COUNTX(
    FILTER(testresult, NOT(ISBLANK(testresult[is_correct]))),
    testresult[is_correct]
)
```

Количество правильных и неправильных ответов:

```
_correct_answer_test = SUM(testresult[is_correct])

_incorrect_answer_test =
[_all_answers_test] - [_correct_answer_test]
```

Рейтинг пользователя по тестам:

```
_test_rating =
SUMX(
    testresult,
    [is_correct] * [question_contribution]
)
```

Расчёт вклада вопроса:

```
question_contribution =
SUMMARIZE(
    'test',
    test[id],
    "question_cnt", DISTINCTCOUNT('testquestion'[id]),
    "com", MAX('test'[complexity])
)
```

#### **2.4. Результаты выполнения практических задач**

Количество успешных отправок:

```
_correct_submit =
COUNTX(
    FILTER('codesubmit', NOT(codesubmit[is_false])),
    codesubmit[id]
)
```

Общее количество отправок:

```
_total_submit =
[_incorrect_submit] + [_correct_submit]
```

Время выполнения в минутах:

```
time_spent_in_minutes =
IF(
    ISBLANK(codesubmit[time_spent]),
    0,
    codesubmit[time_spent] * 60
)
```

Доля неуспешных отправок:

```
_complexity_problem =
DIVIDE(
    [_incorrect_submit],
    [_incorrect_submit] + [_correct_submit]
) * 100
```

Рейтинг пользователя по практическим задачам:

```
_problem_rating =
SUMX(
    SUMMARIZE(
        FILTER('codesubmit', [is_false] = 0),
        codesubmit[user_id],
        codesubmit[problem_id],
        "rating", MAX('codesubmit'[COM])
    ),
    [rating]
)
```

Общий рейтинг:

```
_total_rating = [_problem_rating] + [_test_rating]
```

### **3. Реализация страниц отчёта**

#### **3.1. Страница «Прогресс»**

Страница содержит 14 визуальных элементов и предназначена для анализа общей активности и учебного прогресса пользователей.

| Визуальный элемент                                                 | Значимость                                                                                                                                                         |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Карточка `_DAU`                                                    | Показывает среднее дневное количество активных пользователей. Позволяет оценить интенсивность ежедневного использования платформы.                                 |
| Карточка `_MAU`                                                    | Отражает среднее месячное количество активных пользователей. Помогает оценить масштаб аудитории, регулярно взаимодействующей с платформой.                         |
| Карточка `_Stickiness`                                             | Показывает соотношение дневной и месячной активности. Позволяет оценить регулярность возвращения пользователей на платформу.                                       |
| Столбчатая диаграмма «Правильные и неправильные ответы по курсам»  | Сравнивает результаты пользователей в разрезе курсов. Помогает определить направления, в которых возникает больше затруднений.                                     |
| Круговая диаграмма «Кол-во активных и неактивных пользователей»    | Показывает структуру пользовательской базы по активности. Позволяет оценить соотношение вовлечённых и неактивных пользователей.                                    |
| Кольцевая диаграмма «Соотношение кол-ва тестовых вопросов и задач» | Сравнивает объём двух типов учебной активности. Помогает понять, какая часть учебного взаимодействия приходится на тестирование, а какая — на практические задачи. |
| Воронка «Рейтинг пользователей»                                    | Отображает распределение пользователей по рейтингу. Позволяет выделить наиболее результативных участников и оценить различия в результатах.                        |
| Сводная таблица Rolling Retention                                  | Показывает показатели удержания на горизонтах 3, 7, 14 и 30 дней. Позволяет сравнить возвращаемость пользователей на разных временных интервалах.                  |
| Срез по курсу                                                      | Ограничивает анализ выбранным курсом. Позволяет сравнивать активность и результаты отдельных учебных направлений.                                                  |
| Срез по дате                                                       | Задаёт временной период анализа. Позволяет изучать показатели за выбранный интервал.                                                                               |

#### **3.2. Страница «Тесты»**

Страница содержит 15 визуальных элементов и предназначена для анализа результатов тестирования.

| Визуальный элемент                                     | Значимость                                                                                                                     |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Индикатор «Кол-во правильных ответов»                  | Сопоставляет количество правильных ответов с общим количеством. Позволяет быстро оценить результативность тестирования.        |
| Карточка количества тестов                             | Показывает количество тестов в выбранном контексте. Помогает оценить объём тестового материала.                                |
| Столбчатая диаграмма «Рейтинг пользователей по тестам» | Сравнивает результаты пользователей. Позволяет выявить наиболее успешных участников и различия в результатах.                  |
| Карточка ID вопроса                                    | Отображает идентификатор вопроса в выбранном контексте. Помогает связать результат с конкретным тестовым вопросом.             |
| Таблица «Рейтинг тестов по сложности»                  | Представляет тесты в разрезе сложности и результатов. Позволяет сопоставить характеристики тестов и успешность их прохождения. |
| KPI «Тренд кол-ва заходов по месяцам»                  | Показывает изменение количества заходов по месяцам. Позволяет отслеживать динамику активности в разделе тестирования.          |
| Круговая диаграмма «Кол-во тестов по сложности»        | Показывает распределение тестов по уровням сложности. Помогает оценить структуру тестового материала.                          |
| Карточка признака правильности ответа                  | Показывает, был ли выбранный ответ правильным. Позволяет детализировать результат тестирования.                                |
| Срез по дате                                           | Ограничивает результаты выбранным временным периодом. Позволяет анализировать динамику тестирования.                           |
| Срез по курсу                                          | Позволяет рассматривать результаты тестов отдельно по учебным направлениям.                                                    |
| Дополнительный срез по дате                            | Обеспечивает дополнительную настройку временного отбора данных на странице.                                                    |

| Кольцевая диаграмма отправок и запусков кода            | Показывает соотношение записей об отправках решений и запусках кода. Помогает различать активность по отправке и исполнению решений.                |
| Карточка названия задачи                                | Отображает название выбранной задачи. Позволяет идентифицировать объект анализа.                                                                    |

| Столбчатая диаграмма «Рейтинг пользователей по задачам» | Сравнивает результаты пользователей при выполнении практических заданий. Помогает выявить наиболее результативных участников.                       |
| Таблица «Сложные задачи (по % неверных ответов)»        | Выделяет задачи с высокой долей неуспешных решений. Помогает обнаружить задания, которые могут требовать дополнительного объяснения или пересмотра. |
| Срез по курсу                                           | Позволяет анализировать выполнение задач в рамках выбранного курса.                                                                                 |
| Срез по дате                                            | Ограничивает анализ выбранным периодом выполнения задач.                                                                                            |

### **4. Фильтрация и взаимодействие**

Для отбора данных используются срезы по курсам и датам. На страницах применяются отдельные календарные таблицы:

- `calendar_progress` — активность пользователей;
- `calendar_test` — результаты тестирования;
- `calendar_problems` — выполнение задач.

Фильтрация позволяет анализировать показатели в разрезе выбранного курса и временного периода. Точное поведение перекрёстной фильтрации между визуализациями требует проверки в Power BI Desktop.

### **5. Вывод реализации**

В результате реализации создан интерактивный аналитический отчёт Power BI, включающий три страницы: «Прогресс», «Тесты» и «Задачи».

Для анализа используются DAX-меры, позволяющие рассчитывать показатели активности пользователей, удержания, правильности ответов, успешности выполнения практических заданий и пользовательского рейтинга.

Визуализации представлены в виде карточек, диаграмм, таблиц и KPI-индикаторов. Фильтры по курсам и датам позволяют детализировать показатели и рассматривать результаты за выбранные периоды.

Разработанный отчёт обеспечивает наглядное представление данных об активности и результатах обучения. Его структура позволяет анализировать показатели как в целом по платформе, так и отдельно по тестированию и практическим заданиям.
