# Добро пожаловать в экосистему Андекс!
Экосистема бизнеса Андекс представляет собой молодую и динамично развивающуюся сеть компаний, объединенных общей целью обеспечить клиентам удобство и доступность различных услуг. В рамках данной экосистемы представлены следующие компании:

- **Андекс Университет** — образовательная онлайн-платформа, предлагающая курсы по Data Science, Python, SQL, аналитике данных, математике и другим техническим направлениям. Обучение сочетает теорию, тестирование и практические задания.

- **Андекс Продукты** — розничная торговая сеть из 20 магазинов разных форматов, расположенных в нескольких регионах России. Ассортимент включает продовольственные и непродовольственные товары повседневного спроса.

- **Андекс Еда** — сервис доставки продуктов питания и готовых блюд с широким ассортиментом товаров различных категорий. Сервис обеспечивает обработку заказов, управление ассортиментом и доступность востребованных товаров.

- **Андекс Практик** — образовательная платформа для изучения программирования с упором на практику. Студенты выполняют задания в онлайн-редакторе кода, где автоматически проверяются решения и фиксируются результаты обучения.

- **Андекс Аптека** — аптечная сеть, предлагающая лекарственные препараты, медицинские изделия и товары для здоровья и красоты. Компания развивает онлайн-заказы и обеспечивает доступность аптечной продукции для клиентов.

Экосистема бизнеса Андекс стремится обеспечить клиентам все необходимые услуги в одном месте, упрощая их повседневную жизнь и обеспечивая удобство и доступность различных сервисов. Компания Андекс довольно молодая, и для развития всей экосистемы генеральный директор обратился за помощью в аналитике. Глобальная цель — увеличить количество клиентов экосистемы и средний чек в каждом из продуктов.
