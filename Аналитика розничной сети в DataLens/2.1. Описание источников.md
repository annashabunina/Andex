# Источники

## «Аналитика розничной сети Андекс Продукты»

### 1. Состав датасета
| Лист | Размер | Описание |
|---|---:|---|
| `fact_sales` | 81 238 строк | Таблица фактов — все продажи сети за 2024–2025 годы. Основной источник для дашбордов. |
| `dim_products` | 101 строка | Справочник товаров: наименование, бренд, категория, подкатегория, цены, поставщик. |
| `dim_stores` | 20 строк | Справочник магазинов: 20 магазинов в 4 регионах, 3 формата (у дома / супермаркет / гипермаркет). |


### 2. Связи между таблицами							
fact_sales.id_товара   →  dim_products.id_товара	

fact_sales.id_магазина →  dim_stores.id_магазина	

### 3. Описание таблиц
#### 3.1. `fact_sales`

| Поле | Тип | Описание |
|---|---|---|
| `id_чека` | Целое | Номер чека. В одном чеке несколько строк-позиций, поэтому значение повторяется. Для подсчёта числа чеков нужен DISTINCTCOUNT. |
| `дата_время` | Дата/время | Дата и время покупки. Содержит и время — для связи с календарём по дню это важно учитывать. |
| `id_магазина` | Целое | Ключ магазина. Связь с `dim_stores`. |
| `id_товара` | Целое | Ключ товара. Связь с `dim_products`. |
| `id_клиента` | Целое / пусто | Ключ держателя карты. Пусто, если покупка без карты лояльности (~45% чеков). Связь с `dim_customers`. |
| `количество` | Целое | Сколько единиц товара в этой строке чека. |
| `цена_за_единицу` | Дробное | Цена одной единицы товара на момент покупки, руб. |
| `скидка_процент` | Целое | Размер скидки на строку, %. 0 — без скидки. Скидки бывают только у держателей карт. |
| `сумма_строки` | Дробное | Итоговая сумма строки с учётом количества и скидки, руб. Главное поле для расчёта выручки. |
| `способ_оплаты` | Текст | Как оплачен чек: «карта», «наличные» или «СБП». |


#### 3.2. `dim_products`

| Поле | Тип | Описание |
|---|---|---|
| `id_товара` | Целое | Уникальный ключ товара. Первичный ключ таблицы. |
| `наименование_товара` | Текст | Название товара, например «Молоко 3.2% 1л». |
| `бренд` | Текст | Бренд товара. Для товаров без бренда — «—». |
| `категория` | Текст | Категория, например «Молочка», «Бакалея». Всего 14 категорий. Основной разрез для анализа. |
| `подкатегория` | Текст | Подкатегория внутри категории, например «Молоко», «Сыр». |
| `цена_закупки_руб` | Дробное | Закупочная цена, руб. Нужна для расчёта маржи. |
| `цена_розничная_руб` | Дробное | Базовая розничная цена, руб. |
| `id_поставщика` | Целое | Ключ поставщика. Связь с `dim_suppliers`. |

#### 3.3. `dim_stores`

| Поле | Тип | Описание |
|---|---|---|
| `id_магазина` | Целое | Уникальный ключ магазина. Первичный ключ таблицы. |
| `наименование_магазина` | Текст | Название, например «Соседушка Центральный». |
| `формат_магазина` | Текст | Формат: «у дома», «супермаркет» или «гипермаркет». Разрез для сравнения форматов. |
| `город` | Текст | Город магазина. |
| `регион` | Текст | Регион: «Москва и МО», «Санкт-Петербург и ЛО», «Нижегородская обл.», «Татарстан». Основной географический разрез. |
| `площадь_кв_м` | Целое | Площадь магазина, кв. м. |
| `дата_открытия` | Дата | Когда магазин открылся. |
