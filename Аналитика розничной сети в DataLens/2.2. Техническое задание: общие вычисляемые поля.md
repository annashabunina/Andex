# Техническое задание: общие вычисляемые поля
## 1. Базовые показатели продаж

### 1.1. Выручка

**Название поля:** `Выручка`

**Тип:** показатель

**Формула:**

```
SUM([сумма_строки])
```

**Назначение:**

Общая выручка от продаж.

**Использование:**

- Выручка по месяцам.
- Выручка по магазинам.
- Выручка по регионам.
- Выручка по категориям и товарам.

### 1.2. Количество проданных единиц

**Название поля:** `Количество проданных единиц`

**Тип:** показатель

**Формула:**

```
SUM([количество])
```

**Назначение:**

Общее количество проданных единиц товара.

**Использование:**

- Продажи по категориям.
- Продажи по товарам.
- Анализ ассортимента.

### 1.3. Количество чеков

**Название поля:** `Количество чеков`

**Тип:** показатель

**Формула:**

```
COUNTD([id_чека])
```

**Назначение:**

Количество уникальных чеков.

**Использование:**

- Количество чеков за период.
- Сравнение магазинов.
- Анализ покупательской активности.
- Расчёт среднего чека.

### 1.4. Средний чек

**Название поля:** `Средний чек`

**Тип:** показатель

**Формула:**

```
SUM([сумма_строки]) / COUNTD([id_чека])
```

**Назначение:**

Средняя выручка на один уникальный чек.

**Использование:**

- Sales Performance.
- Сравнение магазинов.
- Динамика среднего чека.

### 1.5. Средняя фактическая цена продажи

**Название поля:** `Средняя фактическая цена продажи`

**Тип:** показатель

**Формула:**

```
SUM([сумма_строки]) / SUM([количество])
```

**Назначение:**

Средняя фактическая цена продажи одной единицы товара с учётом структуры проданных объёмов.

**Использование:**

- Сравнение товарных категорий.
- Анализ подкатегорий.
- Анализ ценового позиционирования.
- Динамика средней цены продажи.

## 2. Вычисляемые измерения

### 2.1. Год продажи

**Название поля:** `Год продажи`

**Тип:** измерение 

**Формула:**

```
YEAR([дата_время])
```

**Назначение:** выделение года продажи.

**Использование:** сравнение 2024 и 2025 годов.

### 2.2. Месяц продажи

**Название поля:** `Месяц продажи`

**Тип:** измерение

**Формула:**

```
DATETRUNC([дата_время], "month")
```

**Назначение:** группировка продаж по месяцам.

**Использование:**

- Monthly Revenue Trend.
- Monthly Revenue by Store.
- Monthly Revenue by Supplier.

### 2.3. Квартал продажи

**Название поля:** `Квартал продажи`

**Тип:** измерение

**Формула:**

```
DATETRUNC([дата_время], "quarter")
```

**Назначение:** группировка продаж по кварталам.

### 2.4. Статус карты лояльности

**Название поля:** `Статус карты лояльности`

**Тип:** измерение

**Формула:**

```
IF(
    [id_клиента] IS NULL,
    "Без карты",
    "С картой"
)
```

**Назначение:** разделение продаж на идентифицированные и неидентифицированные.

**Использование:**

- Loyalty Card vs Non-Loyalty Sales.
- Сравнение выручки.
- Сравнение количества чеков.




## 3. Показатели себестоимости и прибыли

### 3.1. Оценочная себестоимость

**Название поля:** `Оценочная себестоимость`

**Тип:** показатель

**Формула:**

```
SUM(
    [количество] * [цена_закупки_руб]
)
```

**Назначение:**

Оценочная себестоимость проданных товаров по текущей закупочной цене из справочника.

### 3.2. Оценочная валовая прибыль

**Название поля:** `Оценочная валовая прибыль`

**Тип:** показатель

**Формула:**

```
SUM([сумма_строки])
-
SUM(
    [количество] * [цена_закупки_руб]
)
```

**Назначение:** оценочная валовая прибыль.

### 3.3. Оценочная валовая маржа

**Название поля:** `Оценочная валовая маржа`

**Тип:** показатель

**Формула:**

```
(
    SUM([сумма_строки])
    -
    SUM([количество] * [цена_закупки_руб])
)
/
SUM([сумма_строки])
```

**Назначение:** оценочная валовая маржа.
